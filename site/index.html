Mechanism

How it works

Seed truth into Sibyl

Sources and dependents live in Sibyl Memory as the sole semantic store — not a parallel JSON fact cache.

Correct one source

Approve a correction or open a dispute. Versioning uses archive + new body under UNIQUE (tenant_id, category, name).

Kill the process. Fresh cold start.

Empty history. RETRACT reads truth only from Sibyl after a genuine cold start.

Dependents withdraw and rebuild

Press-brief regenerates from corrected sources. The control artifact (company-blurb) stays byte-identical.

Editorial desk UI runs locally at http://127.0.0.1:8765 — not a hosted product surface.
